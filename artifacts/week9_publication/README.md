# Week 9 publication package

This derivative package reads the completed E1–E4 studies. It contains publication figures, T1, full plotting data, claims, captions and benchmark/literature notes.

- `package_state.json` records the lifecycle and binds the final visual review.
- `manifest.json` binds every immutable package file.
- `figure_manifest.json` distinguishes new layouts from byte-identical source copies.
- `tables/T1.md` summarizes the complete classifications and all six unresolved cases.
- `tables/T1_e2.csv`, `tables/T1_e1.csv` and `tables/unresolved.csv` retain all eligible classifications.
- `claims.json` carries numerical values, source selectors, uncertainty and qualifications.
- `source_catalog.json` pins baseline Git objects and all consumed saved bytes.
- `notes/week9_reproduction.md` gives exact reproduction and review commands.

The derivative verification does not extend the original numerical audit/replay scope. μ relative-to-truth metrics remain undefined. Reported comparisons are pointwise; classifications describe discrete investigated designs.
